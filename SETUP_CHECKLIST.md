## ⏳ Por hacer (Pasos siguientes)

### 1. Crear repositorio GitHub `oponoticias-web`
```bash
# En github.com
- New repository → oponoticias-web
- Make it public
- Add .gitignore (Node, macOS)
```

### 2. Pushear la web rediseñada al repo
```bash
cd /Users/alex/oponoticias
git init
git add .
git commit -m "Initial: magazine-style web redesign"
git branch -M main
git remote add origin https://github.com/Alexog91/oponoticias-web.git
git push -u origin main
```

### 3. Conectar Vercel
```
- Vercel.com → Import Project
- Select oponoticias-web repo
- Deploy
- (Vercel auto-deploy en cada push a main)
```

### 4. Configurar GitHub Secrets en repo `oponoticias`
**GitHub → oponoticias → Settings → Secrets and variables → Actions → New repository secret**

Agregar estos 6 secretos:
```
TELEGRAM_TOKEN           = (obtener de @BotFather en Telegram)
TELEGRAM_CHAT_ID         = (obtener de getUpdates API)
SUPABASE_URL            = (proyecto Supabase → Settings → API)
SUPABASE_API_KEY        = (proyecto Supabase → Settings → API, anon key)
ANTHROPIC_API_KEY       = (console.anthropic.com → API Keys)
GITHUB_TOKEN            = (GitHub → Settings → Developer settings → PAT)
```

### 5. Crear GitHub Actions workflow
**En repo `oponoticias`: crear archivo `.github/workflows/daily-boe.yml`**

Contenido:
```yaml
name: Daily BOE Check
on:
  schedule:
    - cron: '30 7 * * *'  # 9:30 CEST (UTC+2)
  workflow_dispatch:       # Permite ejecución manual

jobs:
  check-boe:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-python@v4
        with:
          python-version: '3.11'

      - name: Clone web repo
        run: |
          git clone --depth 1 https://x-access-token:${{ secrets.GITHUB_TOKEN }}@github.com/Alexog91/oponoticias-web.git

      - name: Run leer_boe.py
        env:
          TELEGRAM_TOKEN: ${{ secrets.TELEGRAM_TOKEN }}
          TELEGRAM_CHAT_ID: ${{ secrets.TELEGRAM_CHAT_ID }}
          SUPABASE_URL: ${{ secrets.SUPABASE_URL }}
          SUPABASE_API_KEY: ${{ secrets.SUPABASE_API_KEY }}
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          WEB_REPO_PATH: ./oponoticias-web
        run: python3 leer_boe.py
```

### 6. Crear tabla en Supabase
**Supabase → SQL Editor → New query:**

```sql
CREATE TABLE convocatorias (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  fecha TEXT NOT NULL,
  titulo TEXT NOT NULL UNIQUE,
  enlace TEXT NOT NULL,
  resumen TEXT,
  cuerpo TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_titulo ON convocatorias(titulo);
CREATE INDEX idx_fecha ON convocatorias(fecha DESC);
```

## ❓ Preguntas frecuentes

**P: ¿Cuándo se ejecuta el script?**
A: 9:30 CEST (7:30 UTC) todos los días. Puedes ejecutarlo manualmente en GitHub Actions.

**P: ¿Qué pasa si el script falla?**
A: GitHub Actions lo intentará de nuevo según la configuración. Revisa los logs en Actions.

**P: ¿Cómo agrego más categorías?**
A: Crea `/categoria/[nombre].html` usando `categoria/educacion.html` como plantilla.

**P: ¿Puedo cambiar la paleta de colores?**
A: Sí, edita las variables CSS en `assets/style.css` (líneas 10-19).

**P: ¿El dominio oponoticias.com es tuyo?**
A: Debes registrarlo y configurar los DNS apuntando a Vercel.

## 📞 Soporte

Si algo falla:
1. Revisa los logs en GitHub Actions
2. Verifica todas las variables de entorno están configuradas
3. Confirma que los repos existen y están públicos
4. Prueba el script localmente con `python3 leer_boe.py`
