# OpoNoticias — Automatización y Despliegue

## Arquitectura

```
┌─────────────────────────────────────────────────────────┐
│  leer_boe.py (Python + GitHub Actions)                 │
│  - Lee RSS del BOE diariamente a 9:30 CEST            │
│  - Publica en Telegram @OPONOTICIAS                    │
│  - Guarda en Supabase                                  │
│  - Genera HTML por convocatoria                        │
│  - Regenera sitemap.xml                                │
│  - Hace commit a GitHub → Vercel deploya               │
└─────────────────────────────────────────────────────────┘
                          ↓
        ┌─────────────────┴─────────────────┐
        ↓                                   ↓
   Telegram @OPONOTICIAS            GitHub oponoticias-web
   (256+ suscriptores)              (Vercel auto-deploy)
        ↓                                   ↓
   Canal actualizado                 oponoticias.com
   diariamente                       (nuevas páginas)
```

## Variables de Entorno Necesarias

En **GitHub Secrets** del repo `oponoticias` (donde está `leer_boe.py`):

```
TELEGRAM_TOKEN=         # Token del bot de Telegram
TELEGRAM_CHAT_ID=       # ID del canal @OPONOTICIAS
SUPABASE_URL=          # URL de Supabase (ej: https://xxxxx.supabase.co)
SUPABASE_API_KEY=      # API Key de Supabase (anon key)
ANTHROPIC_API_KEY=     # API Key de Claude (para resúmenes)
GITHUB_TOKEN=          # Token PAT de GitHub (repo scope: public_repo, repo)
```

### Cómo obtener cada token:

#### 1. TELEGRAM_TOKEN y TELEGRAM_CHAT_ID
- Crear bot en Telegram: conversa con @BotFather en Telegram
- Copiar token que te da
- Para CHAT_ID del canal:
  - Crear canal público `@OPONOTICIAS`
  - Enviar un mensaje de prueba
  - Acceder a `https://api.telegram.org/botTU_TOKEN/getUpdates`
  - Copiar el `chat_id` de la respuesta JSON

#### 2. SUPABASE_URL y SUPABASE_API_KEY
- Crear proyecto en https://supabase.com
- Dashboard → Configuración → API → copiar `Project URL` y `anon key`
- Crear tabla `convocatorias` con campos:
  ```sql
  CREATE TABLE convocatorias (
    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    fecha TEXT,
    titulo TEXT UNIQUE,
    enlace TEXT,
    resumen TEXT,
    cuerpo TEXT,
    created_at TIMESTAMP DEFAULT NOW()
  );
  ```

#### 3. ANTHROPIC_API_KEY
- Crear cuenta en https://console.anthropic.com
- Copiar API Key de Settings

#### 4. GITHUB_TOKEN
- En GitHub: Settings → Developer settings → Personal access tokens → Tokens (classic)
- New token: scopes `repo` (public_repo, repo)
- Copiar token

## GitHub Actions Workflow

Crear archivo `.github/workflows/daily-boe.yml` en repo `oponoticias`:

```yaml
name: Daily BOE Check
on:
  schedule:
    - cron: '30 7 * * *'  # 9:30 CEST = 7:30 UTC
  workflow_dispatch:

jobs:
  check-boe:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-python@v4
        with:
          python-version: '3.11'

      - name: Clone web repo
        run: |
          git clone --depth 1 https://x-access-token:${{ secrets.GITHUB_TOKEN }}@github.com/Alexog91/oponoticias-web.git
          ls -la oponoticias-web/

      - name: Run leer_boe.py
        env:
          TELEGRAM_TOKEN: ${{ secrets.TELEGRAM_TOKEN }}
          TELEGRAM_CHAT_ID: ${{ secrets.TELEGRAM_CHAT_ID }}
          SUPABASE_URL: ${{ secrets.SUPABASE_URL }}
          SUPABASE_API_KEY: ${{ secrets.SUPABASE_API_KEY }}
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          WEB_REPO_PATH: ./oponoticias-web
        run: python3 leer_boe.py
```

## Flujo de Ejecución

1. **9:30 CEST diariamente** (GitHub Actions dispara el workflow)
2. **leer_boe.py** se ejecuta:
   - Lee RSS del BOE
   - Filtra convocatorias de oposiciones
   - Para CADA convocatoria nueva:
     - Envía a Telegram (@OPONOTICIAS)
     - Guarda en Supabase
     - Genera archivo HTML en `/convocatoria/[slug].html`
   - Regenera `sitemap.xml`
   - Hace `git commit` y `git push` a `oponoticias-web` en rama `main`
3. **Vercel detecta el push** y redeploya automáticamente
4. **oponoticias.com se actualiza** con las nuevas páginas

## Archivos Generados

Cada convocatoria genera un archivo así:

```
convocatoria/profesores-cuerpos-docentes-almeria-2026.html
```

Contenido:
- SEO completo: title, meta description, og:image, canonical
- JobPosting schema (datos estructurados para Google)
- Breadcrumb navegable
- Contenido con requisitos y detalles
- Enlace directo al BOE
- Sidebar con widget Telegram

## Localización

El script se ejecuta **siempre** en la zona UTC del servidor GitHub Actions. 

Para disparar a **9:30 CEST (horario español)**, usa cron: `30 7 * * *`

- CEST = UTC+2 (marzo-octubre)
- CET = UTC+1 (noviembre-febrero)
- GitHub Actions siempre usa UTC, así que 7:30 UTC = 9:30 CEST (mayormente)

Si necesitas ser más preciso con el cambio de horario, usa: `30 8 * * *` como compromiso (8:30 UTC).

## Troubleshooting

### El script falla en GitHub Actions
- Revisar logs en GitHub Actions
- Verificar todas las variables de entorno están configuradas
- Probar localmente: `python3 leer_boe.py` (en máquina con variables de entorno)

### No se genera el HTML
- Verificar que `WEB_REPO_PATH` está correcto (`./oponoticias-web`)
- Confirmar que el directorio `/convocatoria/` existe en `oponoticias-web`

### El push a GitHub falla
- Verificar que `GITHUB_TOKEN` tiene permisos de `repo`
- Confirmar que el token no ha expirado

### Vercel no redeploya
- En Vercel: revisar Deployments
- Vercel debería auto-detectar pushes a `main` en `oponoticias-web`
- Si no, configurar webhook manual en Vercel Settings
